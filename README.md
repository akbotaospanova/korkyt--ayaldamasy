# «Қорқыт аялдамасы»: даналық жолда

Қорқыт атаның нақыл сөздері мен қазақ мақалдарын сәйкестендіруге арналған интерактивті ойындар. Ойындар қала аялдамаларындағы сенсорлы экранға, автобус мониторына және QR арқылы жолаушының телефонына орнатылатын етіп жобаланған.

## Ойындар

1. **«Жұбын тап»**: аялдамадағы сенсорлы экран. Қорқыт нақылына сай мақалды табу керек. Ойын 5 жұптан тұратын 2 раундтан құралады.
2. **«Даналық маршруты»**: автобус мониторы. Маршрутта 10 аялдама бар, әр аялдамада үш нұсқаның біреуін таңдайсыз.
3. **«Кім айтты?»**: QR арқылы телефонда ойналады. Берілген сөздің Қорқыт атанікі ме, әлде халық мақалы ма екенін анықтайсыз.

## Іске қосу

Сайт бір ғана файлдан тұрады: `index.html`. Оны браузерде ашсаңыз болды, қосымша бағдарлама орнатудың қажеті жоқ.

GitHub Pages арқылы жариялау: **Settings → Pages → Branch: main / (root) → Save**.
Vercel арқылы жариялау: репозиторийді импорттаңыз. Баптаулар қажет емес.
